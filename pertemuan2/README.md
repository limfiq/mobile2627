# Pertemuan 2: Pengenalan Expo dan React Native

Folder ini berisi materi dan praktikum **Pertemuan 2** tentang komponen-komponen dasar pada React Native dan integrasi Expo.

---

## 📌 Topik Pembahasan

1. **Komponen Dasar React Native**: Pemahaman tentang elemen `<View>`, `<Text>`, `<Image>`, dan `<StatusBar>`.
2. **Struktur File Project**: Memahami fungsi `App.js`, `app.json`, `index.js`, dan struktur folder `assets/`.
3. **Eksekusi Proyek**: Running aplikasi pada peranti fisik (HP) melalui Expo Go, Emulator Android, maupun Web Browser.

---

## 🚀 Cara Menjalankan Project

```bash
# 1. Masuk ke direktori pertemuan2
cd pertemuan2

# 2. Install paket dependensi
npm install

# 3. Jalankan aplikasi dengan Expo
npx expo start
```
