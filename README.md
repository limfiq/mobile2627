## 🚀 Cara Penggunaan Repository

### 1. Prerequisites (Prasyarat)
Pastikan Anda sudah menginstal:
* [Node.js](https://nodejs.org/) (versi LTS direkomendasikan)
* Aplikasi **Expo Go** di Android / iOS (jika ingin running di perangkat fisik) atau Emulator (Android Studio / Xcode).

### 2. Clone Repository
```bash
git clone https://github.com/username/Mobile2627Ganjil.git
cd Mobile2627Ganjil
```

### 3. Menjalankan Proyek Pertemuan
Pilih folder pertemuan yang ingin dijalankan (contoh: `pertemuan4`):

```bash
# Masuk ke folder pertemuan
cd pertemuan4

# Install dependensi (jika belum di-install)
npm install

# Jalankan Expo Dev Server
npx expo start
```

### 4. Menguji Aplikasi
* **Perangkat Fisik (HP):** Buka aplikasi **Expo Go**, lalu scan QR code yang tampil di terminal.
* **Android Emulator:** Tekan huruf `a` di terminal.
* **Web Browser:** Tekan huruf `w` di terminal.
