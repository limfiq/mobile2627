# Pertemuan 1: Konsep Dasar Sistem Informasi Berbasis Mobile & Setup Environment

Folder ini berisi proyek awal praktikum **Pertemuan 1** untuk mata kuliah *Sistem Informasi Berbasis Mobile*.

---

## 📌 Topik Pembahasan

1. **Pengenalan Sistem Informasi Berbasis Mobile**: Konsep arsitektur aplikasi mobile dan perkembangannya.
2. **Setup Environment**: Instalasi Node.js, Expo CLI, dan konfigurasi environment React Native.
3. **Inisialisasi Project Expo**: Struktur direktori proyek React Native berbasis Expo.

---

## 🚀 Cara Menjalankan Project

```bash
# 1. Masuk ke direktori pertemuan1
cd pertemuan1

# 2. Install paket dependensi
npm install

# 3. Jalankan aplikasi dengan Expo
npx expo start
```
